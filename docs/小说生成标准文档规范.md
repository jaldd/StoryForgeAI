## 八、写作规范要求

### 8.1 字数要求
- **单章字数**：每章不少于2000字，不超过2500字
- **总字数**：全书约50万字（300章）
- **字数控制**：每章必须达到最低字数要求，不得偷工减料

### 8.2 内容密度
- **生活场景**：占70%，详细描写日常细节
- **异常场景**：占30%，风异常事件要有足够细节
- **对话内容**：符合人物性格，自然流畅
- **心理描写**：细腻真实，展现人物内心变化

### 8.3 格式规范
- **章节标题**：第xxx章_标题
- **段落格式**：每段不宜过长，保持阅读节奏
- **标点符号**：规范使用，避免错误
- **文件格式**：txt格式，UTF-8编码

### 2.7 正文 (06_正文/)

**作用**：实际的章节内容。

**命名规范**：`第XXX章_章节标题.txt`

**格式说明**：
- 使用纯文本格式（.txt），方便提交发表
- 不包含元数据，元数据统一存储在进度管理文档中
- 分段使用空行，章节标题使用"第XXX章 章节标题"格式

**示例**：

```
第一章 风静时

傍晚六点四十。

城市的光还没有完全亮起来。

天色是一种介于灰蓝与暗紫之间的颜色，高架桥尽头的云层被压得很低。空气里带着热意，却没有夏天那种黏腻，而是一种干燥的闷。

风从北面下来。

不是突然起的。

它是慢慢压下来的。

...
```

**元数据管理**：
- 章节元数据（字数、主要人物、场景等）存储在 `07_进度管理/全书进度表.md` 中
- 方便集中管理和查询

## 三、文档编号规则

### 3.1 编号体系

- `00_` - 总纲
- `01_` - 世界观设定
- `02_` - 人物设定
- `03_` - 场景设定
- `04_` - 全书大纲
- `05_` - 分卷提示词
- `06_` - 正文
- `07_` - 进度管理
- `08_` - 素材库

### 3.2 章节编号

- 格式：`第XXX章_章节标题.txt`
- 示例：`第001章_风静时.txt`、`第100章_云开人间.txt`

### 3.3 分卷编号

- 格式：`第X卷_卷名.md`
- 示例：`第一卷_风落云边.md`、`第五卷_与她看云.md`

## 四、文档维护规则

### 4.1 写作前

1. 查看 `00_总纲.md`，确认全书定位
2. 查看 `04_全书大纲.md`，确认当前章节规划
3. 查看 `05_分卷提示词/第X卷_xxx.md`，确认本章具体要求
4. 查看 `07_进度管理/全书进度表.md`，确认写作检查清单

### 4.2 写作中

1. 遵循 `00_总纲.md` 中的写作风格和禁忌
2. 参考 `02_人物设定.md`，确保人物行为一致
3. 参考 `03_场景设定.md`，确保场景描写一致
4. 参考 `07_进度管理/全书情绪曲线.md`，控制情绪温度

### 4.3 写作后

1. 保存正文到 `06_正文/第XXX章_xxx.txt`
2. 更新 `07_进度管理/全书进度表.md`：
   - 添加章节元数据（字数、主要人物、场景、情绪温度等）
   - 更新角色出场计数器
   - 更新场景使用率
3. 检查是否需要埋设或回收伏笔，更新 `07_进度管理/伏笔地图.md`
4. 检查人物关系是否有变化，更新 `07_进度管理/防崩人物关系演化图.md`

### 4.4 定期检查

- **每10章**：检查角色出场计数器、人物组合密度、情绪温度
- **每20章**：检查时间线、场景使用率、章节类型平衡
- **每卷结束**：全面检查所有进度管理文档，规划下一卷

## 七、总结

本规范提供了一套完整的小说生成文档结构和管理方法，包括：

1. **文档目录结构**：清晰的文档分类和命名规范
2. **核心文档说明**：每个文档的作用和必须包含的内容
3. **文档编号规则**：统一的编号体系
4. **文档维护规则**：写作前、中、后的文档维护流程
5. **文档质量标准**：确保文档质量的检查清单

使用本规范，可以：

- 提高小说写作的效率和质量
- 确保小说的一致性和连贯性
- 避免常见的写作问题（如人物崩坏、剧情混乱、伏笔遗忘等）
- 方便团队协作和知识传承

### 8.2 常见问题

**Q1：为什么正文要用 `.txt` 格式？**
A：纯文本格式文件小，方便提交发表，大多数小说平台接受的是纯文本格式。

**Q2：为什么要有这么多进度管理文档？**
A：长篇小说容易出现人物崩坏、剧情混乱、伏笔遗忘等问题，进度管理文档可以帮助避免这些问题。

**Q3：这些文档都要人工维护吗？**
A：可以开发工具自动维护部分文档，如角色出场计数器、场景使用率等。

**Q4：如果小说比较短，可以简化吗？**
A：可以。短篇小说可以合并部分文档，如将世界观设定、人物设定、场景设定合并为一个文档。
